# Krystolen (PC web prototype)

Co-op roguelite prototype: you and three AI Krystalkers explore a fogged map, gather Krystals, beat Gatekeepers and a Dungeon Master.

Play online: https://feeva2498.github.io/Krystolen/ (GitHub Pages, from the `main` branch root).
Or open `index.html` in a browser (keyboard + mouse). Everything is a single self-contained HTML file.

Source: `krystolen-src.bundle` is a git bundle of the full source (`git clone krystolen-src.bundle krystolen`), built with `bash build.sh`.

Controls: WASD move, LMB attack, Space utility, Q skill, E item, F interact, M map, middle mouse ping, Esc menu.
