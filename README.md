# Krystolen (PC web prototype)

Co-op roguelite prototype: you and three AI Krystalkers explore a fogged map, gather Krystals, beat Gatekeepers and a Dungeon Master.

Play: open `index.html` in a browser (keyboard + mouse). Everything is a single self-contained HTML file.

Controls: WASD move, LMB attack, Space utility, Q skill, E item, F interact, M map, middle mouse ping, Esc menu.
